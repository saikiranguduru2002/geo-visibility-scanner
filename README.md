# GEO Intelligence Platform

A tool to analyze how brands appear in AI search systems like ChatGPT, Perplexity, and Google AI Overviews.

---

## 🚨 Problem
Brands don’t know if they appear in AI-generated answers—and existing SEO tools don’t explain why.

---

## 💡 Solution
Scan a brand’s website and evaluate its AI visibility using entity signals like:
- Knowledge Graph
- Schema markup
- Crawlability
- On-page signals

---

## ⚙️ How It Works
Input → Scan → Analyze → Score → Recommend fixes

**Input:** Brand name + URL  
**Output:**
- GEO Score (0–100)
- Grade (A–F)
- Exclusion points
- Actionable playbook

---

## 🔍 Example Output

- Score: 58 (Grade: C)
- Issues:
  - Missing Knowledge Graph entity
  - Weak schema markup
- Fixes:
  - Add Organization schema
  - Strengthen entity references

---

## 🧠 Key Concept

AI visibility is driven by **structured entity signals**, not traditional SEO rankings.
